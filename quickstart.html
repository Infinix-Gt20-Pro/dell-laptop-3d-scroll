How to Set as DEFAULT in ANY Application

// 1. Include in HTML Head:
<link rel="stylesheet" href="path/to/liquid-glass.css">
<script src="path/to/liquid-glass.js"></script>
// 2. Use the Class or Web Component Anywhere:
<div class="liquid-glass">Your Content</div>
<liquid-glass-container>Your Cards</liquid-glass-container>
<liquid-glass-switch checked></liquid-glass-switch>
// 3. In React / Vue / Svelte:
import { LiquidGlass } from './liquid-glass.js';
useEffect(() => { LiquidGlass.init(); }, []);
